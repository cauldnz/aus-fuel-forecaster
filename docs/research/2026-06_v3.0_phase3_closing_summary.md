# v3.0 Phase 3 closing summary — augmentor is dead; ship Model A

**Date:** 2026-06-08 (closing)
**Branch:** `claude/v3.0-kfold-cv`
**See also:** [`2026-06_v3.0_phase2_outcome.md`](2026-06_v3.0_phase2_outcome.md), [`2026-06_v3.0_phase2_postmortem_discussion.md`](2026-06_v3.0_phase2_postmortem_discussion.md)

## TL;DR

The Phase 2 outcome ([`2026-06_v3.0_phase2_outcome.md`](2026-06_v3.0_phase2_outcome.md)) showed that **0 of 8 v2.x augmentor variants survive k-fold validation**. The postmortem ([`2026-06_v3.0_phase2_postmortem_discussion.md`](2026-06_v3.0_phase2_postmortem_discussion.md)) proposed three readings — A (genuinely flat), B (methodology too strict), C (wrong features / model class) — and listed five concrete next-step experiments ranked by signal-value / cost. **Phase 3 ran the top four** and produced a decisive result: **Reading A confirmed beyond reasonable doubt. Reading C falsified in its strongest form (C2). Reading B closed by the literature.**

The decision: **ship Model A** (no SA2 block) as the production model. Retire the SA2 augmentor from the mainline path. Archive the v2.x feature work as a methodology study — the validation contribution is real (single-split misleads), the feature contribution is null.

## The four Phase 3 experiments

| # | Experiment | Cost | Outcome | What it tells us |
|---|---|---|---|---|
| 1 | Per-fold rank consistency across 8 Phase 2 experiments | 0.5 day, no compute | Mean ρ +0.198; cluster + outlier pattern; fold_6 = 61% of variance | Partial Reading A; sharpens C — most augmentor variants share a per-fold ranking pattern, suggesting a missing structural feature |
| 2 | 6× Model A seed-noise floor | ~50 min compute | Seed-Δ stdev 0.136; ratio published/seed = 2.89; folds 3+6 intrinsically volatile | Reading A confirmed — augmentor "noise band" is well within 3× of pure seed jitter |
| 3 | Explicit SEIFA × day-of-fortnight interaction (Reading C2) | ~18 min compute | Mean Δ MAE +0.670 c/L (vs +0.215 baseline) — 3× WORSE | Reading C2 **falsified** — the explicit interaction actively hurts on every fold except fold_1 |
| 4 | Optuna hyperparameter sweep for Model A (Reading C1) | overnight | **WEAK WIN — Mean improvement 0.170 c/L across 6 seeds, ratio 1.29**. New defaults locked into spec §8.2. See [`results/v3_phase3_hyperopt_summary.md`](../../results/v3_phase3_hyperopt_summary.md) + [`results/v3_phase3_hyperopt_validation.md`](../../results/v3_phase3_hyperopt_validation.md). | Reading C1 partially confirmed — Model A was over-fitting at the v1/v2 defaults; smaller more-regularized trees with no row bagging unlock ~0.17 c/L. |

## Detailed findings

### #1 Per-fold rank consistency — cluster-with-outlier pattern

[`results/v3_phase3_rank_consistency.md`](../../results/v3_phase3_rank_consistency.md)

Per-fold Δ MAE matrix across the 8 Phase 2 experiments:

| Fold | pr_b | e1 | e2 | e3 | e4 | e4a | e4b | e5 | Tally |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---|
| fold_1 | +0.07 | +0.02 | −0.10 | −0.02 | −0.03 | −0.04 | +0.11 | +0.02 | 4B / 4A |
| fold_2 | −0.14 | −0.10 | +0.44 | +0.04 | +0.50 | +0.47 | +0.38 | +0.36 | 2B / 6A |
| fold_3 | +0.26 | +0.22 | +0.29 | +0.43 | −0.48 | +0.59 | +0.76 | −0.41 | 2B / 6A |
| fold_4 | −0.10 | +0.07 | −0.08 | −0.02 | +0.13 | +0.46 | +0.02 | +0.11 | 3B / 5A |
| fold_5 | +0.15 | −0.65 | +0.26 | −0.38 | +0.28 | +0.07 | +0.26 | −0.28 | 3B / 5A |
| fold_6 | +1.04 | +1.74 | +0.12 | +1.64 | −0.61 | +1.48 | +0.73 | +0.50 | 1B / 7A |

Headline numbers:
- **Mean pairwise Spearman ρ: +0.198** (median +0.371)
- **Fold_6 alone = 61% of cross-experiment variance**
- **Zero folds have unanimous sign** across all 8 experiments
- **e4_dens+cur** is an outlier (peer-ρ −0.43) — the only experiment that helps on fold_6

The cluster pattern (7 of 8 experiments at moderate positive ρ with each other) said "there's a shared per-period structure most experiments are failing on (fold_3, fold_6)" — which kept Reading C alive at this stage. The e4 anti-correlation said "one variant breaks the pattern on the volatile fold". This is exactly the question #3 was designed to answer.

### #2 Seed-noise floor — folds 3 and 6 are intrinsically unstable

[`results/v3_phase3_seed_noise_summary.md`](../../results/v3_phase3_seed_noise_summary.md)

Ran Model A only across all 6 folds, 6 times, varying only LightGBM's `random_state` (seeds 42, 1, 7, 13, 99, 123). Computed:

| Measurement | Value |
|---|---:|
| Mean per-fold seed-stdev of MAE_A | **0.089 c/L** |
| Mean across-pairs Δ-stdev (15 pairs) | **0.136 c/L** |
| Published Δ MAE stdev (B vs A) | 0.394 c/L |
| **Ratio (published / seed)** | **2.89** |

The per-fold seed-stdev structure is the key finding:

| Fold | Seed stdev | Seed range |
|---|---:|---:|
| fold_1 | 0.054 | 0.15 |
| fold_2 | 0.034 | 0.10 |
| **fold_3** | **0.163** | **0.48** |
| fold_4 | 0.033 | 0.09 |
| fold_5 | 0.069 | 0.19 |
| **fold_6** | **0.178** | **0.55** |

**Folds 3 and 6 have 3-5× higher seed-stdev than folds 1/2/4.** These are exactly the folds dominating cross-experiment Δ MAE variance (#1). What looked like "the augmentor is unstable on those folds" is largely **LightGBM being intrinsically training-unstable on those folds even with zero data change**.

Ratio of 2.89× means: the augmentor's "noise band" (0.394 c/L stdev) is no more than ~3× larger than what two same-model different-seed runs disagree by (~0.136 c/L). The augmentor IS adding some noise on top of seed jitter (the residual ~0.26 c/L), but the published mean (+0.215 c/L) is well within that combined noise envelope. Reading A is now strongly supported.

### #3 Interaction experiment — Reading C2 falsified

[`results/v3_phase3_e6_seifa_dof_interaction_headline.md`](../../results/v3_phase3_e6_seifa_dof_interaction_headline.md)

Added the explicit `sa2_seifa_x_dof = sa2_seifa_irsd_score * cal_day_of_fortnight` column to Model B's feature set and re-ran k-fold.

| Fold | PR B baseline | With interaction | Change |
|---|---:|---:|---:|
| fold_1 | +0.074 | **−0.107** | helped |
| fold_2 | −0.135 | +0.897 | **much worse** |
| fold_3 | +0.260 | +0.740 | worse |
| fold_4 | −0.098 | +0.323 | worse |
| fold_5 | +0.147 | +0.167 | same |
| fold_6 | +1.042 | **+2.001** | **worst — nearly doubled** |
| **Mean Δ MAE** | **+0.215** | **+0.670** | 3× worse |
| Stdev | 0.394 | 0.684 | worse |
| Verdict | noise | noise (B loses more) | — |

LightGBM gain importance on the new column ranked 46-58 (out of ~89 Model B features), with gain values 5,773-40,110 — the model **actively splits on it** but the splits don't generalise. This is a "feature used to overfit training-set spurious patterns" outcome, not a "model couldn't find the interaction" outcome.

Most damning: fold_6 (the 2026 spike) went from +1.042 to +2.001 — the interaction **nearly doubled the augmentor's harm on the exact fold the Reading-C2 hypothesis was meant to help**.

**Reading C2 falsified.** The cleanest test of "GBM is missing a Centrelink × SEIFA interaction" failed actively.

### #4 Hyperparameter sweep — WEAK WIN, new defaults locked

[`results/v3_phase3_hyperopt_summary.md`](../../results/v3_phase3_hyperopt_summary.md) +
[`results/v3_phase3_hyperopt_validation.md`](../../results/v3_phase3_hyperopt_validation.md)

Optuna TPE Bayesian search over Model A's LightGBM hyperparameters,
evaluated on the v3.0 6-fold k-fold harness. Two runs:

- **Run 1 (overnight)**: 3 trials completed in 8.5h — pathological trial 2
  (num_leaves=255, lr=0.014) ate ~8h alone; MedianPruner was dormant
  (n_startup_trials=5). Best at 5.158 c/L (worse than spec default 5.062).
- **Run 2 (tightened constraints, 6h budget)**: 30 trials processed
  (6 DONE, 24 PRUNED). Search space tightened (num_leaves max 127, lr min
  0.01), MedianPruner activated at n_startup_trials=2, per-trial 12-min
  wall-clock cap added as defensive backstop. **Best: trial 15 at 4.8612
  c/L** — improvement of 0.200 c/L vs spec default (single seed 42 only).

**6-seed validation** (Phase 3 #2 protocol applied to the run-2 winner):
mean improvement across folds **0.170 c/L**, stdev across folds **0.132**,
ratio |mean|/stdev **1.29** → **WEAK WIN** (>1.0 weak threshold, <2.0
robust threshold). All 6 seeds show the same pattern: 5 of 6 folds improve
clearly, fold_2 is dead-flat:

| Fold | Seed-mean improvement |
|---|---:|
| fold_1 | −0.213 |
| fold_2 | +0.006 |
| fold_3 | **−0.380** |
| fold_4 | **−0.232** |
| fold_5 | −0.018 |
| fold_6 | **−0.180** |

Biggest wins are on the volatile folds (3, 4, 6) where Model A was
struggling most. This is consistent with Reading C1 (under-regularization
at the v1/v2 defaults); the v1/v2 trees were too deep + too easily
overfit on these unstable folds. The new defaults are smaller trees with
heavier leaf regularization and no row bagging.

**Outcome (per the protocol set ex-ante):**
- |Mean improvement| 0.170 > stdev 0.132 → WEAK WIN → **update spec §8.2 with
  new defaults**, with caveat documenting the per-fold spread.
- New `LGBM_PARAMS` committed to `src/fuel_pred/config.py`; spec §8.2
  documents both old and new with the v3.0 retune callout.

**Reading C1 verdict:** partially confirmed. The v1/v2 defaults left ~0.17
c/L on the table for Model A. The improvement is honest (5 of 6 folds, 6
of 6 seeds in same direction) but modest (weak-band rather than robust-
band). Combined with the rest of Phase 3 evidence: Reading A still holds
for the augmentor; Reading C1 unlocks a small additional Model A gain.

## Combined three-readings verdict

| Reading | Final verdict | Evidence |
|---|---|---|
| **A — augmentor surface genuinely flat** | **Confirmed** | Seed-noise ratio 2.89×; no fold has unanimous-sign across 8 variants; explicit interaction makes things worse |
| **B — methodology too strict** | **Closed (by literature)** | Nadeau-Bengio corrected paired t-test is *stricter* than the design-doc heuristic, not looser — applying it would tighten, not relax, the noise verdict |
| **C — wrong features / wrong model** | **C1 partially confirmed; C2 falsified; C3 not justified** | C2 falsified by #3 (interaction actively hurts); **C1 partially confirmed by #4** — v1/v2 defaults left ~0.17 c/L on the table for Model A; new tuned defaults committed to spec §8.2 + `config.py`. C3 (different model class) not justified — GBM uses the augmentor features (per Phase 2 SHAP) and explicitly given features (per #3); neither helps |

## Decision tree

```
Did Phase 3 #4 (hyperopt) improve val-MAE by > 0.05 c/L vs spec default?
├── YES → Update spec §8.2 with new defaults
│         Re-validate with 6× seed sanity check on new params
│         Then ship Model A on the new defaults
└── NO  → Spec §8.2 defaults are at capacity
          Ship Model A on existing spec defaults
          Reading C1 also falsified
```

Either way: **Model A ships.** The augmentor is retired from the mainline path. The branch that adds back any augmentor work would need to first reproduce a Phase 2-style improvement that survives the v3.0 k-fold methodology — none of the v2.x variants did, and the explicit-interaction probe shows even hand-crafted features don't help.

## What Phase 4 needs to land

1. **Update spec §8.3** to mark the v2.x scheme as deprecated (already done in §15.2 partial). Make Model A the spec-canonical production model.
2. **Update spec §7.7** (SA2 demographic block) to note: kept as feature surface for research, no longer in the production model path.
3. **Update spec §15** to add a Phase 2.5 sub-section pointing at the Phase 3 doc bundle.
4. **Update spec §15.3** to remove "Hyperparameter tuning out of scope" — Phase 3 #4 tested it explicitly.
5. **Rewrite `results/README.md`** with the new headline: methodology-validated single-source-of-truth Model A; what's gone (augmentor dependency, B / B'); what stays (everything else).
6. **Move v2.x's `results/comparison.md`** to a `historical/` subdir; the new headline is `results/v3_phase2_summary.md` + this closing doc + (eventually) the Phase 3 #4 summary.
